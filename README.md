# ワイワイパーティー 🎉

スマホや PC から集まって同時に遊べる、ブラウザのパーティーゲームです。インストールもサーバーもいらず、HTML 1ファイルで動きます。

## 遊び方

1. ホストが「ルームをつくる」を押す
2. 表示された URL(または4文字のルームコード)を友だちに送る
3. みんなが集まったら、ホストがモードを選んで「スタート」

## モード

| モード | 内容 |
|---|---|
| 🍳 ドタバタキッチン | みんなで食材を切って、煮て、盛り付けて、注文をさばくオーバークック風ゲーム |
| 💥 おしくらまんじゅう | 準備中 |
| 💣 ばくだんリレー | 準備中 |
| 🎨 ぬりぬりバトル | 準備中 |

## 操作

| | キーボード | スマホ | ゲームパッド |
|---|---|---|---|
| 移動 | WASD / 矢印 | 画面左をドラッグ | 左スティック / 十字 |
| つかむ・おく | Space / J | つかむボタン | A |
| きる・ダッシュ | Shift / K | きる/ダッシュボタン | X / B |

## 技術メモ

- 通信は [PeerJS](https://peerjs.com/)(WebRTC)による P2P です。ネットワーク環境(会社の回線や一部のモバイル回線など)によっては接続できないことがあります
- ホストのタブが閉じたりバックグラウンドになったりすると、ゲームが止まったり遅くなったりします
