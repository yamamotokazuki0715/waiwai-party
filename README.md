# ワイワイパーティー 🎉

スマホや PC から集まって同時に遊べる、ブラウザのパーティーゲームです。インストールもサーバーもいらず、HTML 1ファイルで動きます。

**▶ 遊ぶ: https://yamamotokazuki0715.github.io/waiwai-party/**

## 遊び方

1. ホストが名前を入れて「ルームをつくる」を押す
2. ロビーに出る URL(または4文字のルームコード)を友だちに送る。URL を開けばコードは入力済み
3. ホストがモードとルールを選んで「スタート」

- 最大8人。1人でも遊べます(対戦モードは人数が足りないと CPU が参加)
- 途中参加もOK。ラウンド制のモードは次のラウンドから参加します

## 操作

基本はどのモードも「移動 + 青ボタン + 赤ボタン」です。ボタンの役割はモードごとに変わり、PC ではゲーム画面の下に、スマホではボタン上に表示されます。

| | キーボード | スマホ | ゲームパッド |
|---|---|---|---|
| 移動 | WASD / 矢印 | 画面左をドラッグ | 左スティック / 十字 |
| 青ボタン | Space / J | 青ボタン | A |
| 赤ボタン | Shift / K | 赤ボタン | X / B |

| モード | 青ボタン | 赤ボタン |
|---|---|---|
| ドタバタキッチン | つかむ・おく | きる(長押し)/ ダッシュ |
| おしくらまんじゅう | ふんばる(長押し) | タックル |
| ばくだんリレー | — | ダッシュ |
| ぬりぬりバトル | せんぷく(長押し) | インクを撃つ(長押し) |
| 蚊の一生 3D(蚊) | 上昇(長押し。離すとゆっくり下降) | 吸う(押すとロックオン先に着陸。長押しで吸う強さアップ) |
| 蚊の一生 3D(人間役) | ふりはらう | たたく |
| 蚊の一生 2D | ダッシュ | 吸う(長押し) |
| ラーメン屋さん 3D | 操作(暖簾・注文・調理・提供・片付け) | お辞儀(押している間ずっと) |

ラーメン屋さんの一人称では、W/S で前後、A/D で横歩き、マウス(画面をクリック)か ←→ で見回します。お辞儀中は視点が下がったまま見回せます。スマホはスティックの上下で前後、左右で旋回します。

## 開発

- コードはすべて [`index.html`](index.html) にあります。ビルドや依存パッケージのインストールは不要です
- ローカルで試すときは HTTP で配信します(複数タブで接続テストをするため)

```bash
python -m http.server 8123
```

- `main` ブランチに push すると、GitHub Pages に自動で反映されます
- 構成やモードの追加方法は [`CLAUDE.md`](CLAUDE.md) にまとめています

## 技術メモ

- 通信は [PeerJS](https://peerjs.com/)(WebRTC)による P2P です。ホストのブラウザがゲームの進行を管理します。ネットワーク環境(会社の回線や一部のモバイル回線など)によっては接続できないことがあります
- 3D モードは [three.js](https://threejs.org/) を使い、モードを始めたときだけ読み込みます
- ホストのタブを閉じたり、バックグラウンドにしたりすると、ゲームが止まったり遅くなったりします
- 登場するお店・人物はすべてオリジナルです。実在の店舗やゲームとは関係ありません
