# ワイワイパーティー 🎉

スマホや PC から集まって同時に遊べる、ブラウザのパーティーゲームです。インストールもサーバーもいらず、HTML 1ファイルで動きます。

## 遊び方

1. ホストが「ルームをつくる」を押す
2. 表示された URL(または4文字のルームコード)を友だちに送る
3. みんなが集まったら、ホストがモードを選んで「スタート」

## モード

| モード | 内容 |
|---|---|
| 🍳 ドタバタキッチン | みんなで食材を切って、煮て、盛り付けて、注文をさばくオーバークック風ゲーム。ステージ4種(ふつう/まっぷたつ/ながーい/せまい)× 難易度4段階(かんたん〜鬼) |
| 🍜 ラーメン屋さん 3D | ひとり席カウンターのとんこつ店で店員になりきる。呼ばれたら暖簾を上げて注文を受け、お好みシート通りに作って提供し、お辞儀。食事中に暖簾を上げると怒られる。協力 / バトル |
| 💥 おしくらまんじゅう | だんだん小さくなる土俵から相手を押し出すバトルロイヤル(3ラウンド制) |
| 💣 ばくだんリレー | 爆発する前に、ぶつかって爆弾を押しつけ合う(3ラウンド制) |
| 🎨 ぬりぬりバトル | 2チームでインクを撃って床を塗り合うスプラトゥーン風チーム戦 |
| 🦟 蚊の一生 3D | 蚊になって部屋を飛び回り、とうさん・ばあちゃん・むすめにバレないように血を吸う3Dゲーム。吸う強さの加減、ツボで落ち着かせる、怒りモードから逃げる。ルールは 協力 / 対戦 / 人間役(1人がとうさんになってたたく)の3つ |
| 🦟 蚊の一生 2D | ボウフラから羽化し、寝ている人間にバレないように血を吸って産卵。たたかれたら次の世代へ。卵の数を競う |

人数が少ないときは、対戦モードに CPU が参加します。

## 操作

| | キーボード | スマホ | ゲームパッド |
|---|---|---|---|
| 移動 | WASD / 矢印 | 画面左をドラッグ | 左スティック / 十字 |
| 青ボタン(モードにより つかむ/ふんばる/せんぷく/ダッシュ) | Space / J | 青ボタン | A |
| 赤ボタン(モードにより きる/タックル/ダッシュ/うつ/すう) | Shift / K | 赤ボタン | X / B |

## 技術メモ

- 通信は [PeerJS](https://peerjs.com/)(WebRTC)による P2P です。ネットワーク環境(会社の回線や一部のモバイル回線など)によっては接続できないことがあります
- ホストのタブが閉じたりバックグラウンドになったりすると、ゲームが止まったり遅くなったりします
